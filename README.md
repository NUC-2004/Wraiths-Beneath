# Wraiths Beneath

一款使用 Unity 制作的 2D 像素风俯视角恐怖潜行游戏。玩家在被黑暗与怪物包围的关卡中移动，利用有限视野辨认环境、寻找出口，并在被追上前完成逃离。

## 项目概览

- 开发周期：2026 年 1 月—5 月
- 引擎：Unity 2022.3.62f1
- 类型：2D 俯视角恐怖、追逐、生存逃脱
- 仓库：[NUC-2004/Wraiths-Beneath](https://github.com/NUC-2004/Wraiths-Beneath)
- 开发分支：[Feature-UI](https://github.com/NUC-2004/Wraiths-Beneath/tree/Feature-UI)

## 核心玩法

```text
进入关卡 → 在有限视野中探索 → 规避怪物追击 → 注视并解锁出口 → 进入下一关
                    ↓                         ↓
                 暂停 / 设置               被捕获：死亡演出与重试
```

## 我的贡献

我负责核心机制与关卡玩法的搭建，将基础地图与角色资源整合为可完整游玩的多关卡恐怖逃脱体验。

### 核心机制

- 实现以玩家为中心的有限视野/光圈机制，并修复光圈移动时的边界问题。
- 实现玩家移动、朝向与动画绑定，完成碰撞体与角色尺寸在不同关卡中的适配。
- 基于 Unity NavMesh 实现怪物追逐、寻路、碰撞判定和动画方向切换。
- 设计视线驱动的怪物加速与追逐反馈，增强探索过程中的紧张感。

### 关卡与流程

- 搭建并完善多关卡玩法，完成关卡 2、关卡 3 的完整流程与场景配置。
- 实现出口交互：玩家需注视出口以推进解锁进度，并获得开门与进度提示反馈。
- 实现通关、失败、重开、场景跳转与暂停流程，使主菜单到关卡游玩的状态切换完整可用。

### 失败演出与体验调校

- 制作死亡流程：停止角色控制、收束视野、死亡插图/音效、失败 UI 与重试入口。
- 实现胜利流程与通关 UI，并处理结束状态下的音频清理和场景切换。
- 调整镜头视野、怪物速度、角色比例和音频状态，提升不同关卡的一致性与可玩性。

## 工程结构

```text
Assets/
├── Scenes/                 # 主菜单、设置与各关卡场景
├── Script/                 # 游戏流程、玩家、怪物、音频与 UI 控制
├── Light/                  # 视野/光圈相关资源
├── NavMesh/                # 导航与怪物寻路配置
├── Prefab/                 # 玩家、怪物、出口等预制体
├── UI/                     # 菜单、暂停、胜利与失败界面资源
└── Sprite/                 # 像素角色、场景与特效资源
```

## 运行方式

1. 使用 Unity Hub 打开项目根目录。
2. 使用 Unity `2022.3.62f1` 或兼容的 Unity 2022 LTS 版本加载项目。
3. 打开 `Assets/Scenes/MenuSecne.unity`。
4. 点击 Unity 编辑器的 Play 按钮，从主菜单进入关卡进行测试。
