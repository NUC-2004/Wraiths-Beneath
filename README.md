# Wraiths Beneath

A three-level horror-game prototype created as a collaborative Unity project.

## Portfolio overview

This repository is presented as a gameplay-design portfolio project. My focus was on gameplay implementation, UI integration, level progression, and bringing the playable build together.

## Features

- Three levels with escalating encounters and pacing
- Player movement and combat interactions
- UI flow, menus, and feedback systems
- Horror atmosphere through environment, sound, and progression

## Run the project

The current playable development version is on the [`Feature-UI`](../../tree/Feature-UI) branch. Open that branch with the Unity version specified in `ProjectSettings/ProjectVersion.txt`, then open the main menu scene and press Play.
